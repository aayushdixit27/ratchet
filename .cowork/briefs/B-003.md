## GUILD — demoted, and here's the honest reason

Their docs index (`docs.guild.ai/llms.txt`, 41 pages) has **no API base URL page, no tracing/spans page, no token-cost endpoint, and no "optimize workspace" page**. What it has is `@guildai/agents-sdk` — a **TypeScript SDK for building agents that run on Guild**, plus workspaces, sessions, credentials, triggers, and an Agent Hub.

Guild is an agent *hosting and governance* platform. Our loop is Python and self-hosted. Using Guild properly means restructuring the agent to run on their platform — that is an hour we do not have at 12:00, and it buys us a fifth sponsor when the criterion asks for three.

### Update 12:10 — read the actual docs pages, refining this

Two paths are now **definitively closed**:
- **No LLM proxy.** Guild "resolves LLM configuration for each session from the workspace owner's account settings" — for agents running *on* Guild. There is no gateway base URL to point our Python at.
- **Coded agents are TypeScript-only.** `"use agent"` directive + Zod schemas, compiled by `babel-plugin-agent-compiler` into a resumable state machine, and the runtime permits only `@guildai/agents-sdk`, `zod`, `@guildai-services/*`. Our loop cannot be one.

But a **third path exists that I missed**, and it's a better fit than tracing ever was. Their CLI treats **skills** as first-class:
```
guild auth login / token
guild skill create <name>
guild skill version create <identifier>
guild agent publish [--wait]
guild session list | get <id> | events <id> | tasks <id>
guild setup            # installs coding-assistant skills into the current project
```
So when `evolve()` detects a step has gone deterministic, it can **publish that learned behaviour as a versioned Guild skill**. That is agents-improving-agents in Guild's own primitives, CLI-driven, no TypeScript. ~25 minutes, and it's a far deeper claim than "we sent them traces."

`guild session events` is also a genuine trace surface, and `guild auth token` proves there's an API under the CLI — a sponsor can name the base URL in ten seconds.

**Decision, revised: stop work on `live_guild.py` as a REST tracer** — that surface doesn't exist. Leave the fixture tracer in place. Live integrations to chase, in order: **Actian → Replay → Pioneer → Senso.** That is four, and four excellent beats five half-done.

**Two honest ways Guild can still count, both cheap, both conditional:**
1. **Skill publication from `evolve()`** (~25 min) — gated behind `evolve()` shipping, which is gated behind the cost curve. Best fit if we get there.
2. **`guild agent publish` to the Agent Hub** (~15 min) — a distribution action rather than a code integration. Do it last, or not at all.

Yoshi is at their table now asking whether the one-button optimize ships and whether skill-publication counts as real use. **Do not start either path until he reports back.** Priority is unchanged: Actian → Replay → Pioneer → Senso.
