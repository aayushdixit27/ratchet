## PRIORITY 1 — this blocks Lane B, do it before anything else
A deliberately buggy web app, **live on a public URL that Replay QA's crawler can reach**. Not localhost. Report the URL in a handoff the moment it's up — don't wait until the rest is done.

- Plain HTML/CSS/JS in `app/`. **No build step, no framework, no bundler.** A small task tracker: add task, edit in a modal, filter, delete-with-confirm, a settings modal.
- Deploy by whatever is fastest to a public URL: drag-drop to Netlify, `vercel deploy`, GitHub Pages, or a `cloudflared tunnel` as last resort. 15-minute cap on deployment; if it blows, tunnel it and tell me.

## The bug seeding — this is the part that makes or breaks the demo
Seed **exactly 8 bugs. Exactly 3 of them must share one class.**

Suggested shared class — `modal-state-not-reset`: three different modals (edit-task, settings, confirm-delete) all fail to clear their internal state on close, so reopening shows stale data. Same root cause, three different selectors, three different-looking symptoms.

That is what makes retention visible by iteration 3: the agent pays full price to reason about the first one, then recognises the other two for pennies. **If the three don't share a genuine semantic root cause, the whole demo falls flat.** Make them truly the same bug wearing different clothes.

The other 5 are singletons — pick obvious ones (dead X button, filter doesn't persist, delete confirm returns wrong boolean, off-by-one in the counter, form submits on Enter when it shouldn't).

Write the full seed list to `app/BUGS.md`: id, class, selector, symptom, real root cause. This is ground truth for scoring and for `FixtureQA`. **It is not shown during the demo** — the agent is supposed to discover these.

## PRIORITY 2 — `dashboard/index.html`, single file, no framework
Tails `runs/ratchet.jsonl` (poll every 2s) and renders:
1. **Cost per verified fix, by iteration** — the hero chart. This line going down IS the pitch. Make it enormous.
2. **Warm vs cold path share** by iteration — stacked bar. Warm should visibly eat cold.
3. **Patterns learned** — a live-appending list: bug class, uses, first-seen iteration.
4. Three big stat tiles at the top: total cost saved, mean steps per fix (now vs iteration 0), patterns in memory.

Design constraints, non-negotiable: **it will be read from 15 feet away on a projector, in a dim room, by tired judges.** Dark background, huge numbers, high contrast, minimal chrome. No animation that delays comprehension. Legibility over beauty.
