```python
@dataclass
class Bug:
    id: str; title: str; root_cause: str; selector: str | None
    repro: list[str]; bug_class: str; raw: dict

@dataclass
class Pattern:
    sig: str; bug_class: str; strategy: str; code_hint: str | None
    verified: bool; uses: int = 0; score: float = 0.0

class QA(Protocol):
    def scan(self, url: str) -> list[Bug]: ...
    def verify(self, url: str, bug: Bug) -> bool: ...
class Memory(Protocol):
    def search(self, text: str, k: int = 3) -> list[tuple[Pattern, float]]: ...
    def upsert(self, p: Pattern) -> None: ...
class Router(Protocol):
    def complete(self, prompt: str, tier: Literal["cheap","strong"]) -> tuple[str, dict]: ...
    # dict -> {"llm_calls":int,"tokens_in":int,"tokens_out":int,"cost_usd":float,"model":str}
class Publisher(Protocol):
    def publish(self, p: Pattern) -> str: ...
class Tracer(Protocol):
    def span(self, name: str, **meta): ...   # context manager
```

## The fast loop — build exactly this

```
for it in range(iterations):
    for bug in qa.scan(url):
        sig  = signature(bug)                 # stable: hash of normalised root_cause + selector shape
        hits = memory.search(bug.root_cause, k=3)
        if hits and hits[0][1] >= WARM_THRESHOLD and hits[0][0].verified:
            patch, usage = apply_known(hits[0][0], bug)   # ONE cheap call, tier="cheap"
            path = "warm"
        else:
            patch, usage = reason(bug)                    # multi-step, tier="strong"
            path = "cold"
        ok = qa.verify(url, bug)
        if ok:
            memory.upsert(Pattern(sig, bug.bug_class, strategy, code_hint, verified=True, uses=+1))
            publisher.publish(pattern)
        emit(record)
    if it % EVOLVE_EVERY == 0 and it > 0:
        evolve()
```

`WARM_THRESHOLD` lives in `policy.yaml`, not in code. So does the cold-path step list. **The agent edits this file.**

## The slow loop — `evolve()`, this is the shock-and-awe
Read the last M records + traces. Find any LLM step whose output has been effectively identical across ≥3 occurrences (normalise whitespace/casing before comparing). For each one, **rewrite `src/ratchet/policy.yaml`** to replace that step with a deterministic rule, and write the before/after diff to `policy_history/<iso8601>-<step>.diff`.

The agent modifying its own policy file, with a diff you can `cat` on stage, is the single most surprising artifact we will show a technical judge. It must work. Prioritise it above any live API.
