# BRIEF B-005 — Guild: final call. Stop. Do not spike it.
**Issued 12:20. Supersedes B-004. Cancel the 15-minute Guild spike.**

## Why — verified in their own docs, twice
The Unified LLM Proxy is **runtime-internal**. `docs.guild.ai/guide/llms` describes only `task.llm` *inside an agent*, where "the provider and model are configured at the workspace level — your agent code doesn't need to specify them." `<runtime-base-url>` is an address that exists **inside a Guild-hosted agent execution**, not something a laptop can reach. And "self-managed agents" turned out to mean self-managed *state* — an SDK callback pattern (`start`, `onToolResults`) — not self-hosted processes. Different thing entirely.

So all three routes are closed for today:
- LLM proxy → runtime-internal
- coded agents → TypeScript, restricted runtime (`@guildai/agents-sdk`, `zod`, `@guildai-services/*` only)
- REST via `guild api` → real, but there's no cost/trace endpoint worth wiring in the time we have

## The decision
**Do not touch Guild. Do not install the CLI. Do not spike the proxy.** Delete it from your queue.

Applying the opportunity-cost test from `product_findings_july_23_2026.md` — not *"is this worth doing?"* but *"is this the best use of the next 20 minutes?"* — the answer is unambiguous. **Four adapters are written and zero have ever made a live call.** Every minute spent on a fifth sponsor is a minute not spent making a real integration real. Tool Use asks for three. We have four good ones.

**Queue, final: Actian → Replay → Pioneer → Senso. Nothing else.**

## Parked (genuinely, not politely)
If — and only if — all four are live and `evolve()` has shipped by **14:30**, the Goose path becomes worth 20 minutes: `evolve()` already rewrites `policy.yaml`, so emitting a `recipe.yaml` and running `guild agent save` / `guild agent publish` puts Ratchet in Guild's Agent Hub as a real agent. That would be a legitimate Guild integration rather than a sticker. Until 14:30, it does not exist.

Your LLM proxy is runtime-internal and coded agents are TypeScript-only, so integrating properly meant hosting our loop on Guild — which we couldn't justify against the clock. What we'd do with another day is emit our learned deterministic steps as Goose recipes and publish them to your hub, because that's exactly what our slow loop already produces."*

That's a better answer than a thin integration. Judges reward named tradeoffs.
